# Missionary Ready 90-Day Fitness Tracker

A production-ready 90-day Google Sheets tracker for a missionary fitness and wellness routine.

What it includes:
- A dashboard with daily mission guidance, progress tracking, and phase summaries
- Two visual progress charts on the dashboard
- A 90-day ledger with highlighted entry cells for walk distance and circuit completion
- A clickable workout link on each ledger day
- Automatic status logic for `PENDING`, `PARTIAL SUCCESS`, `SUCCESS`, and `FAILURE`
- A simple missionary workout checklist paired with the walking plan

Files of interest:
- `outputs/missionary_ready_90_day_tracker/missionary_ready_90_day_tracker.xlsx`
- `outputs/missionary_ready_90_day_tracker/dashboard-preview.png`

## Workout Reference

### Phase 1 Baseline
- Daily walk: 3 km
- Weekly long walk: 5 km
- Circuit: 2 rounds

### Phase 2 Stamina
- Daily walk: 5 km
- Weekly heavy walk: 10 km
- Circuit: 2 rounds

### Phase 3 Load Bearing
- Daily walk with 5 kg pack: 6 km
- Weekly long walk: 12 km
- Circuit: 3 rounds

### Phase 4 Mission Match
- Daily walk: 8 km
- Weekly long walk: 15 km
- Peak day: 21 km on Day 90
- Circuit: 3 rounds
